# Data folder

Organized by measurement type. New data files are written here automatically by the notebooks — see "Where notebooks write" below.

## Subfolders

| Folder              | Contains                                                        | Generated by                                                |
| ------------------- | --------------------------------------------------------------- | ----------------------------------------------------------- |
| `odmr_sweeps/`      | `odmr_sweep_<YYYYMMDD>_<HHMMSS>.csv` ODMR spectra (50 files)    | `01_basic_nv_testing.ipynb` ODMR cell, `Modules/ODMR_module.ipynb` |
| `lockin_twopoint/`  | `twopoint_lockin_*.csv` two-point lock-in time series           | `01_basic_nv_testing.ipynb` lock-in cell, `twopoint_lockin.run_twopoint_lockin` |
| `lockin_multipoint/`| `multipoint_lockin_*.csv` 16-frequency parked acquisitions      | `01_basic_nv_testing.ipynb` multipoint cell, `Modules/Lockin_module.ipynb` |
| `pl_dual_channel/`  | `fast_PL_dual_channel*.csv` photoluminescence comparison        | `01c_dual_channel_fast_pl_validation.ipynb` and friends     |
| `calibration/`      | `8_peaks_*.csv` reference 8-peak full ODMR scans                | One-off calibration acquisitions (used by `nv_toolkit`)     |

## Where notebooks write

Notebooks resolve a save path via the helper `DATA_DIRS` mapping defined in their setup cells. The default routing:

```python
DATA_DIRS = {
    "odmr":            "data/odmr_sweeps",
    "twopoint":        "data/lockin_twopoint",
    "multipoint":      "data/lockin_multipoint",
    "pl_dual_channel": "data/pl_dual_channel",
    "calibration":     "data/calibration",
}
```

If you create new data types, add a key here and a matching subfolder.
