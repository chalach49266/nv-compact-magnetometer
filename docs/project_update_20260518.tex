\begin{itemize}\smallitemsep
  \item New May 18 data: fixed magnet measured at a new spot with the updated live lock-in workflow.
  \item The workflow is still:
  \[
  \begin{aligned}
  \text{ODMR sweep} &\rightarrow \text{16 parked frequencies} \\
  &\rightarrow \Delta f(t) \rightarrow \Delta B(t).
  \end{aligned}
  \]
  \item The same Hampel-based spike rejection is used before frequency-shift and B-field reconstruction.
  \item Latest May 18 reconstruction uses 8 kept transitions and 16 parked frequencies.
  \item The B reconstruction matrix condition number is 6.65 for the May 18 parked-frequency plan.
  \item This deck includes all 30 figures from the new fixed-magnet attachment set.

\begin{frame}{Next steps}
\begin{columns}[T,totalwidth=\textwidth]
\begin{column}{0.50\textwidth}
\begin{itemize}\smallitemsep
  \item Continue tuning the Hampel filter parameters for live lock-in spike rejection.
  \item Verify the B-field reconstruction against controlled field directions and known magnet placements.
  \item Make live B reconstruction faster so sensitivity does not drop from the calculation time.
  \item Add dual-channel measurement.
\end{itemize}
\end{column}
\begin{column}{0.46\textwidth}
\begin{itemize}\smallitemsep
  \item Reduce crosstalk and stray pickup with RF shielding around the soldered region.
  \item Continue hardware optimization for compact operation.
  \item Run the next fabrication dose test after cleaning the old chips.
  \item Longer-term: integrate nanodiamond on-chip and test simple coupling to a SiN microring resonator.
\end{itemize}
\end{column}
\end{columns}
